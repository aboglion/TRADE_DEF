# COIN - نظام تداول خوارزمي

## 📜 نظرة عامة

نظام للتداول الخوارزمي في العملات المشفرة، مكتوب بلغة بايثون. يقوم النظام بجمع بيانات دفتر الطلبات (Order Book) من عدة بورصات في وقت واحد، ويحللها في الوقت الفعلي، ويحفظ البيانات التاريخية لغرض إجراء عمليات محاكاة (Backtesting).

## ✨ الميزات الرئيسية

*   **جمع البيانات من بورصات متعددة**: يسحب البيانات من Binance و Bybit و OKX في وقت واحد.
*   **تخزين البيانات التاريخية**: يحفظ جميع بيانات السوق في قاعدة بيانات TimescaleDB للتحليل المستقبلي.
*   **محرك اختبار الأداء التاريخي (Backtesting)**: يسمح بإجراء محاكاة للاستراتيجية على البيانات السابقة لاختبار الأداء.
*   **جاهز لـ Docker**: تم إعداد النظام بأكمله (التطبيق + قاعدة البيانات) للعمل في بيئة Docker معزولة باستخدام Docker Compose.
*   **إعدادات مرنة**: تحكم كامل في العملات والاستراتيجية وإدارة المخاطر عبر ملف `CONFIG.py`.

## ⚙️ المتطلبات الأساسية

*   Docker
*   Docker Compose (בדרך כלל מגיע עם Docker Desktop)

## 🚀 التثبيت والإعداد

1.  **استنساخ المستودع** (إذا لم تكن قد فعلت ذلك بعد):
    ```bash
    git clone <your-repository-url>
    cd COIN
    ```

2.  **إنشاء ملف البيئة (`.env`)**:
    هذه هي أهم خطوة لإعداد التفاصيل الحساسة. قم بإنشاء ملف جديد باسم `.env` في المجلد الرئيسي (`COIN/`).
    انسخ المحتوى التالي إليه واستبدل كلمة المرور بكلمة مرور قوية خاصة بك:

    ```
    # تفاصيل الاتصال بقاعدة البيانات
    DB_USER="postgres"
    DB_PASSWORD="your_super_secret_password" # <-- استبدل بكلمة مرور حقيقية!
    DB_DATABASE="trading_data"
    DB_HOST="db"
    DB_PORT="5432"
    ```
    > ⚠️ **مهم**: ملف `.gitignore` يمنع رفع هذا الملف إلى مستودع Git، وبالتالي يحافظ على خصوصية كلمة المرور الخاصة بك.

## 🛠️ طريقة الاستخدام

تتم جميع العمليات من المجلد الرئيسي للمشروع (`COIN/`) باستخدام `docker-compose`.

### 1. التشغيل المباشر (جمع البيانات والتداول)

هذا الأمر يقوم بإعداد النظام بأكمله: تطبيق التداول وقاعدة البيانات. في المرة الأولى، سيقوم ببناء صورة (image) التطبيق.

```bash
docker-compose up --build
```

לאחר ההרצה, תראה את הלוגים של המערכת בטרמינל, המציגים את איסוף הנתונים והחלטות המסחר בכל מחזור.
כדי לעצור את המערכת, לחץ `Ctrl+C`.

### 2. הרצת סימולציה (Backtesting)

לאחר שאספת מספיק נתונים בהרצה החיה, תוכל לבחון את האסטרטגיה שלך על תקופות זמן היסטוריות.
השתמש בפקודה `docker-compose run` כדי להריץ את סקריפט ה-`backtest.py` באופן חד-פעמי.

**תבנית הפקודה:**
```bash
docker-compose run --rm app python backtest.py <SYMBOL> "<START_TIME>" "<END_TIME>"
```

**דוגמה:**
הרצת בדיקה על מטבע `BTCUSDT` לתקופה של שעה אחת בתאריך 27 באוקטובר 2023:
```bash
docker-compose run --rm app python backtest.py BTCUSDT "2023-10-27 10:00:00" "2023-10-27 11:00:00"
```

הסקריפט ישלוף את הנתונים הרלוונטיים מבסיס הנתונים, יריץ את הסימולציה, וידפיס סיכום של התוצאות.

## ⚙️ קונפיגורציה מתקדמת (`CONFIG.py`)

קובץ ה-`CONFIG.py` הוא מרכז הבקרה של המערכת. ניתן לשנות בו פרמטרים מרכזיים כדי להתאים את התנהגות הבוט:

*   `SYMBOLS`: רשימת המטבעות למעקב (למשל `["BTCUSDT", "ETHUSDT"]`).
*   `CYCLE_INTERVAL`: מרווח הזמן (בשניות) בין כל מחזור איסוף וניתוח נתונים.
*   `HISTORY_TIME_MINUTES`: כמה דקות של היסטוריה לשמור בזיכרון לצורך חישוב אינדיקatorים.
*   `TAKE_profit_PCT` ו-`STOP_LOSS_PCT`: אחוזי יעד ללקיחת רווח ועצירת הפסד.

לאחר שינוי בקובץ, יש לבנות ולהריץ את המערכת מחדש עם `docker-compose up --build`.
